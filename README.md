## 🚀 Proyectos destacados

### 🖥️ [TuPC.LAB — Explorador de componentes PC](https://github.com/TATAPIERCE-dev/tupc-lab)

Herramienta para comparar componentes de tiendas chilenas, consultar historiales de precios y armar un PC según el presupuesto. Incluye filtros de stock, favoritos y exportación de cotizaciones.

**Python · BeautifulSoup · SQLite · JavaScript**

### 🚌 [TravelEase — Sistema de reserva de buses](https://github.com/TATAPIERCE-dev/SISTEMA-BUSES)

Aplicación para buscar viajes por Chile, filtrar rutas y horarios, seleccionar asientos y gestionar reservas, con pagos simulados y comprobantes de compra.

**AdonisJS · React · Inertia · TypeScript · PostgreSQL**

### 🔧 Serviteca Automotriz - Quiriquina

Sistema interno de gestión y seguimiento de tickets, clientes y reportes, acompañado de soporte técnico para su operación.

**AdonisJS · React · Inertia · TypeScript · PostgreSQL · Docker**
